怎么体验

底部“动作预览”中的走路、跑步、思考、蹲下会持续执行，直到切换或停止。持续跑步会真实累积疲劳：动作逐渐减速、呼吸和心率升高；达到极限后会进入撑膝喘息恢复，恢复后如果你没有取消跑步意图会继续跑。

真实物理身体

Free 版现在使用本地 Rapier 3D 角色物理。NIVA 有独立的胶囊碰撞体、重力、地面吸附、坡度与台阶规则。走路和跑步的世界位移先交给 Rapier Character Controller 计算，再同步到 VRM，因此不再只是让双腿原地摆动。

脚底接触 / Foot IK

左右脚现在分别拥有独立地面接触状态。进入支撑期时，系统用 Rapier Ray Cast 查出脚下真实地面，并把该脚的世界坐标锁成 stance anchor；AnimationClip 先给出步态，再由实时 IK 修正 UpperLeg → LowerLeg → Foot，使支撑脚尽量不随角色 Root 滑动。

蹲下

旧版“固定大角度弯腿 + 双脚平均补偿”已停止作为正式方案。现在蹲下时左右脚分别锁地，角色视觉骨盆平滑下降，腿部只提供很小的初始弯曲趋势，然后由双腿 IK 把脚重新求解到各自地面锚点。也就是说，身体向下时膝盖被腿长和脚底位置共同约束，而不是直接把人物拉成跪姿。

疲劳撑膝

跑步达到极限疲劳后，双脚先锁地，骨盆下降、躯干前倾，同时双臂 IK 分别把左右手拉向左右膝盖附近。呼吸保持高强度，恢复结束后再决定是否继续跑步。这比固定肩肘角度的“假撑膝”更接近真实接触。

生命状态

左上角实时显示心率、呼吸频率和疲劳。疲劳由当前活动负荷和持续时间连续计算，不随机伪造。随机只用于很小的步频波动和微表情，避免机械重复。

控制优先级

手动控制优先于语音和自动行为；恢复动作优先于普通移动；生命微动作位于最底层。语言模型只能选择“走路、跑步、蹲下、恢复”等高层意图，不能直接写 Rapier 坐标、IK 目标或骨骼 quaternion。

下一阶段

当前是 Physics Body V2 的第一版：角色级 Rapier 物理 + 独立脚底锚点 + 实时腿/臂 IK。后续继续加入膝/肘 pole vector、脚跟/脚掌/脚尖三点接触、斜坡足底法线、预测式落脚和重心支撑区域判断。
