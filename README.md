# NIVA Web MVP V0.3 – Rigged

Offline / no API.

Independent transparent layers: body, head, left hair bundle, left arm, right arm, holographic skirt.
SVG facial rig: blink, mouth shapes, blush, brows.
Ambient motion: breathing, hair sway, skirt sway, arm micro-motion.
Public control contract: `NIVA.play({ text, emotion, motion })`.

Open `index.html` directly. `index.dev.html` references the asset folder and is easier to edit.
