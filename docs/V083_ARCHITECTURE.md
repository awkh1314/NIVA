# V0.83 Architecture

V0.81/V0.82 的 Collision Guard 能发现非法姿态，但用户仍可能看到短暂穿模或回弹。V0.83 把碰撞检测前移到规划阶段：只有“终点安全 + 从当前姿态到终点整条路径安全”的候选动作才会进入真实动画队列。

54 个连续自由度无法枚举所有组合，因此用两层缩维：gesture primitive 只激活必要运动链；Safe Pose Bank 围绕常用 gesture、方向、强度和少量变体预计算安全候选。单关节仍可在合法 ROM 内达到高幅度，但不保证多个独立关节极限同时出现。

Coupled Joint Constraints 在碰撞测试前施加人体联动约束：同一球形关节三个轴不能同时叠到各自极限；深屈膝时减少髋部扭转；深屈肘时减少手腕极端角度。

Path Planner 对候选终点先检查碰撞，再把当前姿态到目标姿态分成 8–36 个采样点。任何采样点出现自碰撞，整条动作废弃。真实动画用 quintic smoothstep，几何路径不变，并根据每个骨骼 `maxSpeed` / `maxAccel` 反推最短时长。

DeepSeek 不接触 raw bone，只输出：
```json
{"t":"回答","e":"happy","g":[["wave","r",0.7]],"v":["bright",0.6]}
```
没有必要动作时省略 `g`。gesture 的具体骨骼联动、时长、路径和安全检查都由本地运行时决定。

输入、DeepSeek 响应、TTS 和动作使用 response queue。当前回答未完成时，新输入只进入队列；下一段从上一段最终安全姿态规划，不允许直接重置姿态。

Tauri 窗口透明、无边框、置顶。默认宽度只容纳 NIVA 模型；双击模型后扩展控制面板。展开/收起时读取当前显示器尺寸与窗口位置，将窗口位置 clamp 到显示器可见范围。

语音优先本地 Qwen3-TTS Serena；服务不可用时回退系统 SpeechSynthesis。Qwen 模型权重不提交进 Git，首次安装语音包时独立下载并缓存。
