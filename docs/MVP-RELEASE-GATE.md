# NIVA 0.1 MVP Release Gate

目标：不是做出“功能很多”的 NIVA，而是做出一个可以交给陌生用户安装测试的 Windows 桌面产品。

## P0 · 发给测试用户前必须完成

- [x] Windows NSIS 安装包可自动构建
- [x] 透明、无边框、置顶桌面窗口
- [x] 自然站立作为默认状态，不自动跳舞
- [x] 点击反馈、文字输入、右键拖动、双击设置
- [x] 首次使用引导和前五分钟轻提示
- [x] 未配置 AI 时仍可运行本地行为
- [x] AI 请求失败时自动恢复到本地行为
- [x] 麦克风/语音识别不可用时自动切到文字模式
- [x] 语音失败只提示一次，不进入反复错误提示
- [x] 托盘支持显示/隐藏 NIVA
- [x] 窗口位置持久化，显示器变化后有恢复逻辑
- [x] 本地 VRM 导入与持久化
- [x] 近期对话和有限长期记忆可独立清除
- [x] 单实例：重复启动时聚焦已有 NIVA，而不是再开一个
- [x] 开机启动开关（系统托盘）
- [x] 统一应用健康状态：模型/语音/网络/本地存储故障进入可恢复降级，不留下卡死 UI
- [ ] 真实 Windows 安装机做一次完整冷启动验收
- [ ] 连续运行 2 小时无明显卡死、持续报错或异常占用

## P1 · 20 人测试后再补

- [ ] 自动更新
- [ ] Windows 代码签名
- [ ] 匿名最小化产品指标：启动、首次互动、崩溃、D1/D7
- [ ] 一键反馈入口
- [ ] 全屏/游戏/省电模式下自动降低刷新或暂停渲染
- [ ] 用户可查看 NIVA 当前保留的长期记忆内容
- [ ] 正式固定语音 provider

## 当前冻结项

MVP 通过前不新增：高级 Agent、屏幕理解、插件生态、复杂长期记忆、动作商城、专业动画重做、商业支付体系。

## 0.1 测试版判定

满足全部 P0 后生成 `0.1.0-alpha` 安装包，先给少量真实用户测试。发现的问题优先按“无法安装 / 无法启动 / 无法互动 / 卡死 / 过度打扰 / 不知道怎么用”的顺序修复，而不是继续增加功能。
