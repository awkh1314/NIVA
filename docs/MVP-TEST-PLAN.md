# NIVA 0.1 MVP Test Plan

这份测试只验证“能不能作为一个 Windows 产品交给陌生用户”，不验证动画质量、AI 质量或商业功能。

## A. 冷启动安装验收

建议在 Windows Sandbox、虚拟机或没有运行过 NIVA 的 Windows 用户账户执行。

### 安装

1. 使用 GitHub Actions 生成的 NSIS 安装包安装 NIVA。
2. 不安装开发环境，不克隆源码，不配置 DeepSeek API。
3. 安装完成后直接启动 NIVA。

通过条件：

- 30 秒内人物窗口出现；
- 默认自然站立，不无限跳舞；
- 没有白屏、黑屏、空透明窗口或持续加载；
- 没有 API Key 时仍可点击、文字输入并得到本地反馈；
- 第一次使用能够看到基础引导。

### 桌面行为

依次验证：

1. 右键拖动人物，窗口能够移动并记住位置；
2. 点击人物有反馈；
3. 双击人物能打开设置；
4. 点击右上角关闭按钮后人物隐藏，而不是结束整个程序；
5. 从系统托盘点击 NIVA，人物重新出现；
6. 托盘菜单可以主动退出 NIVA；
7. 连续再次启动 NIVA，不出现第二个人物窗口，已有实例被显示并聚焦。

### 开机启动

1. 托盘右键，勾选“开机自动启动”；
2. 注销 Windows 或重启；
3. 登录后确认只启动一个 NIVA；
4. 再取消“开机自动启动”，再次注销/重启确认不会自动启动。

### 降级行为

至少完成下面三项：

- 不配置 AI：NIVA 仍能运行本地行为；
- 禁止麦克风权限或使用不支持语音识别的环境：NIVA 自动切换文字输入，不循环弹错；
- 临时断网：窗口和人物不消失、不冻结，对话失败后能回到本地行为。

如果有可替换 VRM，再故意选择一个无效文件，确认模型错误不会造成整个应用无响应。

## B. 2 小时稳定性验收

先正常启动 NIVA，然后在仓库目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\mvp-soak-test.ps1
```

默认持续 120 分钟，每 30 秒记录一次 CPU、Working Set、Private Memory、Handles 和 Threads，并生成 `niva-soak-*.csv`。

测试过程中每隔约 15–20 分钟执行一次真实操作：

- 点击人物；
- 隐藏到托盘再恢复；
- 打开/关闭设置；
- 输入一条文字；
- 拖动窗口一次；
- 至少断网再恢复一次。

通过条件：

- 2 小时内 `niva.exe` 不退出；
- 不出现第二个 NIVA 进程；
- 不出现无限 THINKING、无限 LISTENING 或无法恢复的加载状态；
- 内存没有明显持续单向增长；
- 当前脚本将峰值 Working Set > 1200 MB 或峰值/初始值 > 2.5x 标为需要复查；
- 托盘显示/隐藏和退出在测试结束时仍正常。

## C. MVP 发布结论

只有当 `docs/MVP-RELEASE-GATE.md` 中所有 P0 都完成，并且本测试的 A、B 两部分通过，才生成 `0.1.0-alpha` 给第一批真实用户。

测试失败时只修以下问题：无法安装、无法启动、无法互动、卡死、重复实例、窗口找不回来、资源明显失控、用户不知道怎么使用。其他新功能继续冻结。
